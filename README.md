# 📚 NILAM 书籍资料库 (NILAM Book Database)

> 专为 NILAM 读书计划与阅读爱好者打造的精美、沉浸式书籍资料库。支持 1019+ 卷经典书籍与漫画完整资料，包含多语言切换、一键复制填报、阅读状态记录与数据备份功能。

---

## ✨ 核心特性

- 🌟 **海量书籍资料**：收录 1,019 卷精美书籍资料（含火影忍者、排球少年、青春之旅、葬送的芙莉莲、孤独摇滚、迷宫饭、金田一、强风吹拂等经典作品）。
- 🌐 **三语完整适配 (100% Multilingual)**：支持 **中文 (CN)**、**马来文 (Bahasa Melayu)**、**英文 (English)** 深度本地化无缝切换。
- 📝 **NILAM 填报利器**：
  - 每卷均配备精炼**内容概述 (Sinopsis)** 与 **道德启示与品德 (Nilai Murni & Pengajaran / Moral Insights)**（均经精心打磨，启示字数达 150 字以上）。
  - 支持字段单独复制及**一键完整复制整卷信息**。
- 📊 **阅读进度与状态**：支持单卷完成标记、收藏星标、待填报筛选、全馆阅读进度统计。
- 💾 **本地离线储存**：纯前端架构，无需数据库，数据自动保存在浏览器 LocalStorage，并支持 JSON 数据导出与导入备份。
- 🎨 **黑金奢华质感 UI**：采用 Dark Gold Edition 配色，支持流畅卡片视差动画、分类筛选与即时搜索。

---

## 🚀 部署与使用

本项目为纯静态单页面应用（SPA），无需任何后端环境或构建打包：

1. **在线访问 (GitHub Pages)**：
   - 部署到 GitHub Pages 后，访问专属域名即可直接使用全部功能。
2. **本地运行**：
   - 直接双击 `index.html` 即可在任意浏览器中离线流畅运行。
